PASSWORD ATTACKS

Password attacks target user credentials to gain unauthorized access to accounts, systems, and sensitive information.


1. Brute Force Attack

Definition: Attackers try many password combinations until they find the correct one.

Causes:

  • Weak passwords
  • No account lockout
  • Poor authentication security

How to Identify:

  • Multiple failed login attempts
  • Unknown login activity
  • Sudden account lockouts

Prevention:

  • Use strong passwords
  • Enable MFA
  • Limit login attempts

2. Dictionary Attack

Definition: Attackers use a list of common passwords to gain access.

Causes:

  • Common passwords
  • Weak password policies
  • Password reuse

How to Identify:

  • Repeated login attempts
  • Suspicious authentication logs
  • Multiple failed passwords

Prevention:

  • Create complex passwords
  • Use password managers
  • Enable MFA

3. Credential Stuffing

Definition: Attackers use stolen usernames and passwords from previous breaches.

Causes:

  • Password reuse
  • Data breaches
  • Weak account security

How to Identify:

  • Unknown account access
  • Login attempts from new locations
  • Suspicious account activity

Prevention:

  • Use unique passwords
  • Enable MFA
  • Monitor breach alerts

4. Password Spraying

Definition: Attackers try one common password against many accounts.

Causes:

  • Weak password choices
  • Poor password policies
  • Large user databases

How to Identify:

  • Many accounts targeted
  • Common passwords detected
  • Repeated login failures

Prevention:

  • Ban weak passwords
  • Use MFA
  • Monitor login attempts

5. Rainbow Table Attack

Definition: Attackers use precomputed password hash tables to crack passwords.

Causes:

  • Weak hashing algorithms
  • No password salting
  • Poor password storage

How to Identify:

  • Compromised password databases
  • Hash cracking attempts
  • Unexpected account breaches

Prevention:

  • Use salted hashes
  • Use strong encryption
  • Store passwords securely
