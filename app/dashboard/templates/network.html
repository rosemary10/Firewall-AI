NETWORK ATTACKS

Network attacks target computer networks, communication systems, and internet-connected devices to steal data, interrupt services, or gain unauthorized access.


1. Denial of Service (DoS)

Definition: A DoS attack floods a server with traffic to make it unavailable.

Causes:

  • Server flooding
  • Bot traffic
  • Weak network protection

How to Identify:

  • Slow website/server
  • Network crash
  • Too many requests

Prevention:

  • Use firewall
  • Enable traffic filtering
  • Use rate limiting

2. Distributed Denial of Service (DDoS)

Definition: Multiple systems attack a target server simultaneously.

Causes:

  • Botnets
  • Compromised devices
  • Weak cloud protection

How to Identify:

  • Massive traffic spikes
  • Website downtime
  • Connection failures

Prevention:

  • DDoS protection services
  • Load balancing
  • Traffic monitoring

3. Man-in-the-Middle (MITM)

Definition: Attackers secretly intercept communication between users.

Causes:

  • Unsecured Wi-Fi
  • Weak encryption
  • Fake access points

How to Identify:

  • Unexpected logouts
  • Data leakage
  • Suspicious connections

Prevention:

  • Use HTTPS
  • Use VPN
  • Avoid public Wi-Fi

4. ARP Spoofing

Definition: Fake ARP messages are sent to redirect network traffic.

Causes:

  • Weak LAN security
  • Open networks
  • Unmanaged switches

How to Identify:

  • Duplicate MAC addresses
  • Slow connection
  • Unexpected traffic

Prevention:

  • Static ARP tables
  • Use IDS/IPS
  • Secure LAN setup

5. DNS Spoofing

Definition: Attackers redirect users to fake websites using fake DNS records.

Causes:

  • Compromised DNS servers
  • Cache poisoning
  • Weak DNS security

How to Identify:

  • Wrong websites open
  • Fake login pages
  • Certificate warnings

Prevention:

  • Use DNSSEC
  • Use secure DNS providers
  • Enable HTTPS

6. Packet Sniffing

Definition: Attackers capture network packets to steal information.

Causes:

  • Unencrypted traffic
  • Open Wi-Fi
  • Weak protocols

How to Identify:

  • Network anomalies
  • Unauthorized monitoring tools
  • Data leaks

Prevention:

  • Encrypt communication
  • Use VPN
  • Secure Wi-Fi

7. Evil Twin Attack

Definition: Fake Wi-Fi hotspots imitate legitimate networks.

Causes:

  • Public Wi-Fi usage
  • Weak authentication
  • User negligence

How to Identify:

  • Duplicate Wi-Fi names
  • Unexpected login requests
  • Unsecured connections

Prevention:

  • Verify Wi-Fi names
  • Use VPN
  • Avoid unknown hotspots

8. Session Hijacking

Definition: Attackers steal session IDs to access user accounts.

Causes:

  • Weak session security
  • Cookie theft
  • Unencrypted sessions

How to Identify:

  • Unexpected logins
  • Session timeout issues
  • Unauthorized activity

Prevention:

  • Use HTTPS
  • Enable secure cookies
  • Use multi-factor authentication
